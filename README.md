JEJAK PENDIDIKAN MALAYSIA — CODING

Fail:
- index.html : kandungan dan halaman laman web
- style.css : reka bentuk responsif
- script.js : navigasi, butang kembali dan interaksi permainan
- assets/profile-placeholder.svg : gambar contoh untuk diganti

Cara guna:
1. Ekstrak ZIP.
2. Buka folder ini dalam VS Code.
3. Buka index.html dengan browser atau gunakan Live Server.
4. Gantikan assets/profile-placeholder.svg dengan foto anda dan kemas kini laluan imej di index.html.
5. Semak maklumat peribadi dan tambah huraian tokoh/rujukan yang diperlukan berdasarkan penulisan serta rubrik pensyarah.

Nota kandungan:
Laman ini menyediakan bahagian berasingan untuk Semenanjung Malaysia, Sabah dan Sarawak serta aktiviti interaktif. Huraian sejarah ialah rangka pembelajaran ringkas; semak dan lengkapkan butiran serta rujukan akademik sebelum penghantaran.
